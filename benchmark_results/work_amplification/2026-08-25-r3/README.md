# Work-Amplification R3 Capsule

R3 graduates one narrow general mechanism: exact parent-aware component
reduction for heavy-tail paired point/MultiPolygon membership. It explicitly
does not select the analogous Q10 attribute reducer, and it archives two
constructive algebra rewrites that had the wrong physical shape.

Authoritative files:

- `RESULTS.md`: decisions and complete-workflow measurements;
- `OPPORTUNITY_MAP.md`: ranked general follow-up mechanisms;
- `PLAN.md`: frozen experiment protocol;
- `sf100_q10_q11_final_lean_cold1.json` and
  `results_sf100_q10_q11_final/`: exact SF100 decision evidence;
- `shootout_10k_final.json`: current candidate plus validated static comparator;
- `shootout_1m_final_vs_only.json`: current strict-native candidate diagnostic;
- `q11_parent_aware_component.py`: identified one-batch mechanism falsifier;
- `q10_parent_aware_component.py`: protected Q10 counterfactual;
- `vegetation_buffer_union_order.py` and
  `habitat_buffer_union_order.py`: archived constructive falsifiers.

The HTML pipeline report and Python bytecode are generated/ignored and are not
part of the retained capsule or checksum manifest. `SHA256SUMS` covers every
other retained file. `RUN_IDENTITY.json` binds the final source, dataset,
machine, commands, and headline artifact hashes.
